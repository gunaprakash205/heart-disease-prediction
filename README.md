# Heart Disease Risk Prediction

A Machine Learning project that predicts heart disease risk based on patient health and lifestyle information. The project uses a Gradient Boosting Classifier and provides an interactive web interface using Streamlit.

## 🚀 Project Overview

The goal of this project is to build a machine learning model that can classify whether a patient belongs to a lower-risk or higher-risk class based on medical and lifestyle features.

The project includes:
- Data preprocessing
- Exploratory data analysis
- Multiple machine learning models
- Model comparison
- Cross-validation
- Hyperparameter tuning
- Gradient Boosting model
- Model evaluation
- Model saving using Pickle
- Interactive Streamlit application

## 🧠 Machine Learning

Several classification algorithms were compared:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- K-Nearest Neighbors

Gradient Boosting performed best during model comparison and was selected as the final model.

### Final Model

**Gradient Boosting Classifier**

Parameters:
- `n_estimators = 150`
- `learning_rate = 0.1`
- `max_depth = 3`

## 📊 Model Performance

### Test Set

| Metric | Score |
|---|---:|
| Accuracy | 73.26% |

### Cross-Validation

**5-Fold Cross-Validation Accuracy: 73.64%**

## 📌 Features Used

The model uses 11 input features:

- Age
- Gender
- Height
- Weight
- Systolic Blood Pressure
- Diastolic Blood Pressure
- Cholesterol
- Glucose
- Smoking
- Alcohol Intake
- Physical Activity
